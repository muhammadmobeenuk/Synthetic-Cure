## Company setup
Preserve the existing white/navy/jade visual system. A full-width Settings card exposes three saved review steps, current version, explicit unconfirmed values and genuine progress. Incomplete operational onboarding is stated separately. Inline editing preserves entries during network/409 failures and requires review before rebasing. Weekday controls have text labels and touch targets; phones stack step actions. The broader design provider required sign-in and produced no design, so no generated design/fidelity claim is made.

## Access settings

Company/warehouse selection shows authorized choices and preserves draft work before switching. Settings provides actual versioned warehouse identity and membership/grant commands with role, active/revoke state, source reason and conflict feedback. Additional membership never presents an automatic grant to all warehouses. Missing access is a setup/recovery state, not an empty-stock assertion. Existing staff identity provisioning remains explicit. Preserve the established navy/jade tokens and touch controls.

## CSV review
Reuse the existing panels, navy text, jade actions and amber row errors. Three task steps: source/mapping, validation, explicit commit. Required source columns are selected by position, not guessed; ignored columns and unknown handling/conversions remain visible. Row cards replace compressed tables on phone. Source/mapping survives requests; device save is provisional. Persisted batches reopen after reload.
